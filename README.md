ДЗ 3 Docker Еркесикли Тимур БПМИ269

1.Запуск: docker compose up -d --build

2.Адрес: http://localhost:8080

3.Настройки находятся в compose.yaml и .env.example

  Redis сохраняет данные после перезапуска.

4.Приложение работает не от root, запись в системные файлы запрещена, ограничения 0.5 CPU и 256 МБ памяти

5.Проверка: ./scripts/check.sh

  Проверяется работа приложения, сохранение данных и восстановление Redis, создаётся резервная копия.

  Результат: All checks passed

6.Остановка: docker compose down
